Troubleshooting & FAQ

"I uploaded a PDF, but it doesn't seem to have been picked up"

  • Check the file is actually a .pdf and was uploaded directly into 01-Inbound (not a subfolder).
  • Check Job Logs for a recent run on that library – if the most recent run happened before you uploaded, it just hasn't run again yet. Trigger a manual run, or wait for the next scheduled one (see Triggering the Ingest).
  • Check whether the file is now sitting in 02-Processing, 04-Processed, or 99-Error – it may already have been picked up and moved.

"A file is stuck in 02-Processing"

This usually means a run was interrupted partway through. Check the Job Logs entry for that library and time – if the Status is Failed, see the Details column for the reason. If it stays stuck after the next run, contact your development team rather than moving the file yourself.

"A file ended up in 99-Error"

This means the file either failed data extraction or timed out waiting for a result. Review the file to check it's a valid, readable timesheet PDF. Once you've addressed the issue (or if you believe it was a temporary problem), move the file back into 01-Inbound and it will be picked up and retried on the next run.

"The Job Logs list shows Status: Failed"

This means the run for that library couldn't even start (e.g. a temporary SharePoint connectivity issue) – no files were processed at all, not even ones that would otherwise have succeeded. Check the Details column for the reason. If it happens repeatedly, contact your development/platform team.

"The Job Logs list shows Status: Partial Success"

Some files in that run succeeded and at least one failed. Check Details for which file(s) failed and why; the failed file(s) will be in 99-Error. The successful ones are unaffected and will already be in 03-Output/04-Processed.

"Does the application use my PDF Type / Site / Week No. values?"

No. Those columns are purely for your own organization and filtering of the document library – the application doesn't read them and processes files regardless of whether they're filled in. See Classifying Timesheet PDFs.

"How often does it run automatically?"

This depends on your environment's configuration and may not be the same everywhere. Check with your development/platform team, or judge it from the timestamps in the Job Logs list.

"I dropped a non-PDF file in 01-Inbound by mistake"

It's simply ignored – only files ending in .pdf are picked up. You can safely remove it.

"A row in Job Logs shows FilesProcessed = 0 and Details: No files found – is that a bug?"

No – this is expected and just confirms the run happened while that library's 01-Inbound was empty.
