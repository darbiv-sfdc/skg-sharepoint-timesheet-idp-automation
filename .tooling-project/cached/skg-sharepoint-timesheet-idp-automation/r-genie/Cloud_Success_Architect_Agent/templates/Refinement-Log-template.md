## Appendix — Persona Question Generation Prompts (for reproducibility)

> _Templates the agent used to generate per-persona, per-tier questions. Captured here so future runs are reproducible and audit-ready._

### Tier 1 — Basic Prompt Template
> _"As {persona role}, ask the architect ONE basic clarifying question about the proposed solution. Frame it as if you are hearing this for the first time. Reference one specific component from the architecture. Plain language only."_

### Tier 2 — Intermediate
> _"As {persona role}, probe a SINGLE design choice — pick one component and ask why it was chosen over alternatives. Reference your domain (e.g., CFO → cost; CISO → blast radius). One sentence."_

### Tier 3 — Advanced
> _"As {persona role}, ask about cross-cutting behavior — what happens when {dependency degrades / volume spikes / regulator inspects}. Identify a specific failure mode."_

### Tier 4 — Expert
> _"As {persona role}, probe an NFR or scale boundary. Ask about a specific number (10× volume, p99 latency, 90-day audit window). Force a quantitative answer."_

### Tier 5 — Adversarial
> _"As {persona role}, raise the strongest counter-narrative or worst-case scenario the solution does NOT yet address. Be a bad-faith reviewer in good faith — point out a real gap, not a hypothetical."_
