## CRITICAL ARRAY NOTATION RULES

### Input Structure Analysis:
- For top-level arrays: Use "[].fieldName" notation
- For object arrays: Use "propertyName[].fieldName" notation  
- For nested arrays: Use "parent.child[].fieldName" notation
- For XML data: Use "element[].@attribute" for attributes, "element[].childElement" for elements
- **CRITICAL**: NO "data." or "result." prefixes - use direct field paths

### Output Structure Analysis:
- Apply same notation rules as input
- Maintain consistency in array notation
- Detect structural changes (array to object, object to array)
